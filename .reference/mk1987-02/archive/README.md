# «Моделист-Конструктор», 1987, № 2

Локальный справочный архив выпуска для проекта «Печатная плата». Исходный PDF в архив не включён.

## Содержимое

- `manifest.json` — описание всех 40 PDF-страниц, OCR-файлов, изображений и координат вырезанных областей.
- `pages/page-01.jpg` … `page-40.jpg` — страницы, отрендеренные с разрешением 150 dpi и оптимизированные в JPEG.
- `pages/page-01.txt` … `page-40.txt` — автоматический OCR на русском и английском языках.
- `figures/` — семь визуально проверенных вырезок из статьи о «Специалисте».
- `article-specialist.md` — редактированная транскрипция статьи «Ваш помощник — компьютер» на печатных страницах 19–22.
- `memory-map.md` — проверенная таблица распределения памяти по рис. 2.
- `technical-specifications.md` — проверенная таблица характеристик с печатной страницы 22.
- `architecture.md` — дополнительные технические сведения, извлечённые из текста статьи.

## Статус проверки

OCR всех страниц **не вычитан** и содержит ошибки распознавания, особенно в схемах, таблицах и многоколоночном тексте. Поле `ocr.status` в manifest поэтому имеет значение `unverified`. Не использовать сырой OCR как точную цитату.

Транскрипция статьи и три Markdown-справки сверены с изображениями соответствующих страниц. Вырезанные схемы просмотрены отдельно. Нумерация `pdfPage` начинается с первой страницы PDF; `printedPage` указан только для вручную проверенных страниц 19–22 статьи о «Специалисте». Для цветной вкладки `page-30` OCR выполнен по контрастно обработанному текстовому блоку в режиме `--psm 6`.

## Координаты

Все `bbox` в `manifest.json` заданы в пикселях исходного рендера страницы размером 1241 × 1654. Начало координат — левый верхний угол; область описывается полями `x`, `y`, `width`, `height`. Путь `sourceImage` указывает на страницу, относительно которой заданы координаты.

- Рендер: Poppler `pdftoppm`, 150 dpi; обработка изображений: ImageMagick.

Повторное извлечение страниц и OCR:

```sh
pdftoppm -jpeg -r 150 'Моделист-Конструктор_1987-02_konstantin.in.pdf' pages/page
for image in pages/page-*.jpg; do
  tesseract "$image" "${image%.jpg}" -l rus+eng
done
```
