# План развития проекта

Оперативные задачи и их состояние находятся в закреплённом [Roadmap issue #4](https://github.com/Specialist-PK/pechatnaya-plata/issues/4). Этот документ описывает долгосрочные направления и не заменяет GitHub Issues как источник текущих планов. Значимые решения фиксируются в `docs/adr/`.

## Исходный подход

Сайт собирается Bun и Vite как статическое приложение и публикуется через GitHub Pages. Статьи хранятся в Markdown с метаданными, каталог формируется во время сборки, а рендер и пагинация выполняются на клиенте. UI использует собственный JSX-runtime без фреймворка.

## Критерий первой публичной версии

Первая версия готова, когда на опубликованном сайте есть содержание, три законченные статьи, работающие hash-ссылки, одностраничный и двухстраничный режимы, а production-сборка по подпути проверена в браузере.

## Дальнейшее развитие

- архив по выпускам и темам;
- отдельные страницы «О журнале» и «Архив» при увеличении количества материалов;
- более сложная пагинация таблиц, сносок и крупных схем;
- RSS при регулярном появлении новых материалов;
- поиск после накопления достаточного количества статей;
- prerender или гибридный рендер, если понадобятся полноценная работа без JavaScript и улучшение SEO.
