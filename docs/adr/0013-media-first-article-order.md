# 0013. Крупные иллюстрации перед основным текстом

Статус: заменено ADR-0014 (2026-11-04), изменяет ADR-0012

## Контекст

После введения единого увеличенного кегля по ADR-0012 крупные иллюстрации оказались перемешаны с текстом, а некоторые страницы содержали только один визуальный блок после длинных текстовых фрагментов. Для более последовательного чтения крупные изображения должны идти сначала, после чего — параграфы с сопутствующими небольшими иллюстрациями.

## Решение

В начале статьи размещаются заставка, структурная схема, разворот принципиальной схемы и временная диаграмма. Основной текст начинается после них. Карта памяти и технические характеристики остаются в потоке соответствующих параграфов.

Один Markdown-источник задаёт этот порядок и для пагинированного, и для непрерывного мобильного reader. Составная принципиальная схема по-прежнему занимает соседние страницы 20–21. Временная диаграмма находится на странице 22 перед началом текста. Общее число страниц остаётся равным семи, единый размер основных параграфов по ADR-0012 не меняется.

## Альтернативы

- **Журнальное чередование текста и крупных схем.** Ближе к печатному оригиналу, но разбивает чтение при увеличенном кегле.
- **Отдельная галерея с собственным маршрутом.** Требует новой навигации и отдельного представления, избыточна для одной статьи.
- **Изображения только в конце статьи.** Усложняет знакомство с конструкцией перед чтением технического описания.

## Последствия

- (+) Начало статьи образует последовательную визуальную часть, за которой идёт непрерывный текст.
- (+) Мобильный и пагинированный порядок совпадают.
- (+) Разворот принципиальной схемы и единый размер текста сохраняются.
- (−) Композиция больше не следует порядку блоков печатного оригинала.
