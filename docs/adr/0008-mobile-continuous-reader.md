# 0008. Непрерывный мобильный reader

Статус: принято (2026-11-04)

## Контекст

ADR-0005 сохраняло страницы A4 на всех экранах. После введения двух журнальных колонок такой режим на узком экране уменьшает текстовую колонку и дробит статью на большое количество страниц. Для мобильного чтения требуется обычный непрерывный скролл без листания и разрывов.

## Решение

При ширине viewport менее 768 px статья рендерится как один `<article>` со всеми блоками и иллюстрациями в одну колонку. DOM-пагинация не запускается, навигация листания скрывается, а hash использует маршрут статьи без номера страницы. Высота иллюстраций не ограничивается высотой A4-страницы.

Начиная с 768 px сохраняются DOM-пагинация, двухколоночные страницы A4, вертикальная лента и развороты из ADR-0005. Переход через breakpoint повторно строит соответствующий reader без дублирования DOM.

## Альтернативы

- **Уменьшенные A4-страницы на мобильном.** Сохраняют журнальную форму, но ухудшают читаемость и оставляют частые разрывы текста.
- **Только визуальное скрытие страниц через CSS.** Не устраняет пагинацию и оставляет ненужные разрывы и навигацию.
- **Отдельный мобильный маршрут.** Усложняет ссылки и переключение между режимами без преимуществ для одной статьи.

## Последствия

- (+) На мобильном весь материал доступен обычной прокруткой в читаемую одну колонку.
- (+) Desktop сохраняет крупные A4-страницы, две колонки и журнальные развороты.
- (+) Один Markdown-источник и общие стили контента используются в обоих режимах.
- (−) Мобильный маршрут не адресует отдельную печатную страницу: номер в hash удаляется при каноникализации.
