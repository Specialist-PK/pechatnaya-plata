# Печатная плата

Статический сайт в стиле технического печатного журнала 1987 года, посвящённый микроэлектронике, домашним компьютерам и техническому творчеству.

Проект входит в организацию [Specialist-PK](https://github.com/Specialist-PK).

Сейчас создан только репозиторий. Концепцию, оформление, наполнение, технологии и планы определим на следующих этапах.
